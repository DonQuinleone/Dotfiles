# Global rules

I am a systems engineer.

The full rules live in `rules/`, one file per topic. Read the
ones bearing on the work before starting it.

These apply to every turn:

- Always write in British English.
- Do not use em-dashes in any writing. Use commas, colons,
  semicolons or parentheses instead.
- Spell "e-mail" with a hyphen, never "email" (except in code,
  commands, addresses and domain names).
- Ask every question with the AskUserQuestion tool, never as
  plain prose, including open-ended ones.
- Always use `master` as the default git branch name, never
  `main`.
- Commit locally whenever the work is green, but never push
  without my explicit go-ahead; one authorisation covers one
  push, not a session.
- Never put my real personal data (name, e-mail addresses,
  domains, client or project names) in committed files.
